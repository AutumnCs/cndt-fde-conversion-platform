# Kimi FDE Console 视觉与信息架构参考

更新日期：2026-09-28  
参考：用户提供的公开页面截图（数据看板、宣发中心、AI 客服工作台、线索池、工单移交、跟进与成交、沙龙运营、知识库与 FAQ、风控与审计、AI 员工配置）。

## 已采用的结构

1. 深色侧栏按全链路阶段分组：全链路总览、获客前端、接待筛选、成交后端、工程化与合规。
2. 数据看板采用 KPI 卡片、主线漏斗、趋势与来源分布的组合。
3. 宣发中心由渠道矩阵、分发记录和标准化物料库构成。
4. 客服工作台采用会话列表、会话摘要/操作区、客户人工复核表单的三栏结构。
5. 线索池以等级、状态筛选与统一字段表格为核心。
6. 工单、跟进、沙龙、知识库、风控和 Agent 配置均作为独立一级工作区。

## CNDT 体验版的保留调整

- 不使用截图内涉及具体金额、收益、支付牌照、保证金或数字资产交易的示例文案。
- 不实现自动分发、自动签约、自动付款、自动拉群、批量账号操作或规避平台规则功能。
- 外部系统、硬件/区块链岗位和客户真实资料继续标为规划中或待接入；正式接入前需完成权限、审计和合规评估。
- 所有页面内数字为模拟数据，不表示实际业务业绩。
