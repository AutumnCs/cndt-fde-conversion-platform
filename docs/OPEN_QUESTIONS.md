# 待决问题

这些问题会影响完整设计，未确认前不作为既定需求实现。

1. Telegram 试点 Bot 是否可加入目标群组并获得管理员权限，或由群主关闭 Privacy Mode？
2. A/B 类线索的经理确认服务时限是多少？正式 SOP 规定当日移交；1 小时仅是未确认的内部建议，不能视为已定规则。
3. 首批试点团队人数、目标 Telegram 群数量和预估日均新增线索量是多少？
4. 现有中英文资料的格式、存放位置、更新频率和内容合规负责人的发布流程是什么？
5. 是否需要在客户首次互动时展示隐私告知、数据使用说明和人工服务入口？
6. 生产部署偏好是什么：自有服务器、指定云厂商，还是托管服务？数据需落在哪个地区？
7. AI 模型提供方、预算、可用 API 账户及对数据外发的限制是什么？
8. A/B/C 线索评分是否需要可配置权重和人工反馈闭环？一期先采用规则、模型建议或两者结合？
9. 一期成功的业务指标是什么：首次响应速度、A 类识别准确率、经理分配时效、预约率、成交率，还是其他指标？
10. 正式 FDE 方案以 Shopify、Tidio/Gorgias/Zendesk、WhatsApp 和 Instagram Messenger 为建议工具路径；Telegram MVP 是否需要在后续阶段与 Shopify 或现有客服中台汇聚？
11. 会话日志的保留期限、导出审批人、数据地域和删除例外如何确定？正式材料提出“至少 6 年”，但项目仍需将其转化为经过确认的数据治理要求。
