# ADR-0001：以 Telegram 作为一期正式渠道

日期：2026-09-25  
状态：已确认

## 决策

一期仅接入 Telegram，并同时覆盖群聊与私聊；WhatsApp、Facebook、Instagram 只保留未来接入边界，不作为一期交付目标。

## 原因

- 团队优先面向海外市场。
- Telegram 可同时承载社群接待和一对一咨询。
- 先验证“AI 接待 → 线索分级 → 经理确认 → 人工成交”的完整闭环，避免多渠道权限和审核拖慢 MVP。

## 影响

- 需要明确 Bot 的群管理员或 Privacy Mode 配置。
- 需要通过深链接、群内 CTA 等方式引导用户主动开启私聊。
- 渠道模型必须抽象，不能将 Telegram 字段直接写入业务核心。
